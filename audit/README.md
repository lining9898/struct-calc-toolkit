## 自动验证

`python tests/verify_current_standards.py`

环境：Python 3、Playwright Python包、Chromium（默认/usr/bin/chromium）。脚本自动启动临时本地HTTP服务。

- 全部68工具默认页面无JavaScript异常；这不验证每项计算模型。
- 用独立平衡方程计算单筋梁；用中性轴二分迭代验证双筋应变分支。
- 验证柱轴压400上限、净面积反算、超表范围拒绝。
- 验证荷载两种主导情况、不同ψq、100年活荷载与风荷载不同调整、非法输入清空过程。
- 验证矩形/圆形内柱冲切周长、承载力和截面上限；边柱拒绝。
- 验证基础0.15%下限、钢筋面积和整数输入。
- 真实下载Word文件检查β1及界限条文引用，避免只测未使用的导出模板。
