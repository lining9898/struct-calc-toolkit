# 理正模块计算方式对照基线

日期：2026-10-12

本项目开始使用本机 `G:\计算工具箱` 中理正结构工具箱的模块清单和功能说明作为开发参考。参考来源为 `LzTbCadMenu.MNU` 与 `fundesc.txt` 中可观察的模块名称、输入工况和结果能力；没有复制理正的可执行文件、数据库或内部实现。

## 已提炼的计算流程

| 能力 | 理正说明中可观察到的流程 | 本项目推进方式 |
|---|---|---|
| 构件截面 | 梁覆盖矩形、T、工、L、倒L；柱覆盖矩形、工、圆形；配筋可单筋/双筋或对称/非对称 | 把截面分支拆成独立算例，分别核验平衡方程、边界分支和构造限值 |
| 连续梁/梁系 | 多种支座、多种荷载，考虑最不利组合，可调幅并输出内力包络 | 先核对模型自由度和荷载组合，再核对包络、调幅和配筋结果 |
| 板与楼梯 | 矩形板支持弹性/塑性；板式楼梯说明采用有限元，并同时检查梯段和平台 | 对简化板公式与有限元结果分开标识，不把简化结果冒充完整有限元 |
| 基础 | 承载力支持多公式；偏心时考虑基底拉应力及应力重分布；独立基础、条基还验算抗剪/冲切 | 增加偏心、部分脱空、抗剪和冲切的独立参考算例 |
| 桩基 | 独立桩承台、复合桩基、单桩、水平承载和沉降分开处理 | 不把单桩承载力结果直接复用于群桩或复合桩基 |
| 钢结构 | 压弯构件同时验算截面强度和整体稳定；钢连续梁考虑不利组合、侧向约束和整体稳定 | 将强度、稳定、连接分别作为独立输出和测试断言 |
| 砌体与构造 | 砌体高厚比、局压、过梁/圈梁、挑梁、墙梁是不同模块 | 对荷载倒算、施工阶段和局压验算分别建模，避免只复用普通梁公式 |
| 组合/装配式 | 叠合梁、叠合板、接缝和吊装是分阶段问题 | 保持施工阶段、使用阶段、连接验算的结果边界 |

## 第一批落地顺序

1. 梁截面：补齐矩形/T 形梁的剪、扭、裂缝联动，并把单筋/双筋和构造配筋分支单独测试。
2. 连续梁：引入更完整的最不利荷载组合、弯矩调幅和跨间内力包络。
3. 基础：补充偏心受压导致的基底脱空与应力重分布。
4. 桩基：把单桩、群桩承载力、水平承载和沉降的输入输出严格分开。
5. 钢结构与砌体：按理正的模块边界拆分强度、稳定、连接和局压。

## 使用边界

- 理正说明只能说明“模块声称支持什么”，不能单独证明公式正确。
- 理正本机版本和本项目现行规范版本可能不同，材料参数、抗震条文和荷载系数必须以当前规范核验结果为准。
- 未进行黑盒输入输出对照前，映射表中的 `direct` 或 `partial` 只表示主题对应，不表示数值等价。
- `none` 表示目前没有可靠的一对一参考，不应因为名称相近而套用算法。
