# 结构计算工具箱

基于 HTML、CSS 和原生 JavaScript 的结构计算工作台，包含混凝土、钢结构、基础、桩基、砌体等计算工具，支持计算过程展示、Word 计算书导出、收藏和本地参数方案。

## 本地运行

将仓库目录作为静态网站根目录，通过本地 HTTP 服务打开 `index.html`。例如安装 Python 3 后，在仓库目录运行：

```sh
python -m http.server 8000
```

浏览器访问 <http://localhost:8000>。推荐使用 HTTP 服务，避免直接打开文件时浏览器限制知识库等资源加载。

## 自动检查

安装 Node.js 后运行（无需安装第三方 npm 依赖）：

```sh
npm test
```

检查包含矩形梁、受剪梁、T 形梁、连续梁包络、理正模块对照台账和路由回归。路由测试覆盖重复导航、延迟加载、快速切换、未知工具超时和返回首页后的工具状态。

浏览器及 Word 导出检查另见 [规范核验记录](audit/README.md) 和 [Word 导出测试说明](tests/WORD_EXPORT.md)，需要额外配置 Python、Playwright 和浏览器。

## 代码位置

- `src/core/`：材料、共享计算函数、路由和计算书导出。
- `src/tools/`：按专业组织的计算模块。
- `src/ui/`：首页、导航、检索和参数方案等交互。
- `src/knowledge/`：知识库资源。
- `tests/`：计算与交互回归检查。
- `audit/`：逐项核验状态、适用范围和待核验事项。

## 使用范围

工具的规范核验进度和适用范围以 [核验记录](audit/README.md) 及具体模块说明为准。自动测试通过不表示全部计算模型和构造要求均已完成规范核验。用于具体工程前，应由专业人员复核输入、模型、规范适用性与结果。
